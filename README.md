# Computing Environments

Exercises and course material from the **Computing Environments** course of my Master's in Bioinformatics.

## 📖 About

This repository contains the content, notes, and exercises developed throughout the Computing Environments course. The goal is to build a solid foundation in python and practices used to work efficiently and reproducibly in computational biology.


> Folder names are examples and may change as the course progresses.

## 🚀 Getting Started

1. **Clone the repository**
```bash
   git clone https://github.com/your-username/computing-environments.git
   cd computing-environments
```

2. **Create the environment** (when an `environment.yml` is provided)
```bash
   conda env create -f environment.yml
   conda activate computing-environments
```

## 📝 Exercises

Each exercise includes:

- A description of the problem
- The solution (scripts, notebooks, or commands)
- Notes on how to run it and the expected output
